# Домашнее задание к работе 3
## Условие задачи
Написать и отладить программу пересчета килограмм в фунты и унции.

## 1. Алгоритм и блок-схема
### Алгоритм решения
**Начало**

Задать константы для перевода:

`F = 2.20462` _— коэффициент перевода в фунты_

`Y = 35.274` _— коэффициент перевода в унции_

Ввести исходные данные:

`dym` — количество килограмм (вводится пользователем)

Вычислить количество фунтов:

`result = F * dym`

Вычислить количество унций:

`result1 = Y * dym`

Сделать паузу для проверки:

`system("pause")`

Вывести результаты:

Вывод `dym, result, result1`
